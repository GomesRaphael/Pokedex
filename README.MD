# Pokédex Navegável

Este projeto é uma Pokédex interativa que permite buscar e visualizar Pokémon utilizando a PokéAPI. Você pode navegar entre os Pokémon utilizando os botões "Próximo" e "Anterior" ou realizar buscas pelo nome ou número do Pokémon.

---

## Funcionalidades

- Buscar Pokémon pelo nome ou ID.
- Navegar pelos Pokémon utilizando botões de "Próximo" e "Anterior".
- Exibir o nome, ID e sprite animado do Pokémon (quando disponível).
- Mensagem de erro caso o Pokémon não seja encontrado.

---

## Tecnologias Utilizadas

- **HTML5**: Estrutura da interface.
- **CSS3**: Para estilização.
- **JavaScript**: Lógica para busca e renderização de dados.
- **PokéAPI**: API usada para obter os dados dos Pokémon.

---

## Como Usar

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/seu-repositorio/pokedex-navegavel.git
   ```

2. **Abrir o Projeto**:
   Abra o arquivo `index.html` no navegador.

3. **Interagir com a Pokédex**:
   - Use o campo de busca para encontrar um Pokémon pelo nome ou ID.
   - Clique nos botões “Próximo” e “Anterior” para navegar entre os Pokémon.

---

## Estrutura do Projeto

- `index.html`: Arquivo principal contendo a estrutura da interface.
- `script.js`: Contém a lógica JavaScript para interagir com a PokéAPI e atualizar a interface.
- `images/pokedex.png`: Imagem da Pokédex usada na interface.

---

## Exemplo de Uso

- Ao abrir a Pokédex, o primeiro Pokémon (Bulbasaur) é carregado automaticamente.
- Para buscar o Pikachu:
  1. Digite "pikachu" no campo de busca.
  2. Pressione Enter.
- Para navegar para o próximo Pokémon, clique no botão “Próximo”.
- Para voltar, clique em “Anterior”.
